# 机器人本体运行模块

这是从原 master 保留的机器人软件，负责相机、人脸分析、实时语音、ROS 音频和动作索引。它对应论文第三点，尚未接入新研究模型，也未在本轮 Windows CPU 环境做硬件联调。

原来各文件的相对导入关系保留，启动前进入本目录：

```bash
cd robot_runtime
python main.py
```

main.py 默认读取 ROS1 /camera/color/image_raw；音频输出 /audio，播放反馈在原音频管理模块中处理。emotion.py 接收表情和关键词，mic.py 接收话筒指令，ros_audio_sink.py 作为播放侧脚本。test_device.py 用于设备诊断。根据真实机器人节点部署决定在哪台机器启动，不能把所有进程默认视为在 Windows 本机运行。

服务参数在 config.py，鉴权从环境变量读取，名称见 .env.example；该示例不会自动载入。程序会使用 sauc_python/ctrl.txt 和 output.txt 作为已有控制/识别通道，可按部署流程建立，内容不提交到 Git。辅助 ASR 的凭据独立于实时对话凭据。

本轮保留了音频配置的原始输出位宽及 ROS 模式，部署时必须与远端播放端重新核对格式。requirements.txt 只列直接 Python 依赖，ROS 包由机器人系统提供，不保证仅 pip 安装即可重建机器人环境。

代码清理包括：移除重复历史版本；主入口去掉大量废弃采访提示；视觉提示不再被固定提示覆盖；主会话/监控任务结束后进入统一清理；配置移除硬编码凭据，连接日志不再打印鉴权头。其他大部分音频与动作逻辑保持原实现，可能仍存在历史工程问题，正式整机实验前需逐项联调。
