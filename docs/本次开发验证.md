## FQ-Bank 开发基线

使用官方 dev.json 原始 1434 条记录；清理时隔离 56 条相同候选文本同时具备正负标签的记录；在保留记录中移除 129 个同标签重复候选，最终评测 1378 条。

方法为候选集内计算 IDF 的 BM25，使用完整已知历史作为查询，英文词/中文单字分词，知识权重为 0。该方法没有训练，也没有真实知识检索。结果为：

| 指标 | 本次值 |
| --- | --- |
| MRR | 0.128507 |
| Recall@1 | 0.031930 |
| Recall@3 | 0.063135 |
| nDCG@3 | 0.049148 |

原始数据来自 [FQ-Bank 官方仓库](https://github.com/amazon-science/fq-bank)，审计和分数是本地执行得到。它是后续开发的参考起点，**不是原论文复现分数，也不是本项目方法有效性的结论**。去重和冲突隔离改变了任务，正式实验必须说明这个协议；后续应先冻结协议再公平运行所有模型。

本地完整结果：outputs/fqbank-dev-bm25.json；审计：data/processed/fq-bank/dev.jsonl.meta.json。原始文件和转换文件有 SHA256，预测文件保存每条候选分数。数据与运行输出被 Git 忽略；需要迁移时单独复制。
