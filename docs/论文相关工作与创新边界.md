# 论文相关工作与创新边界

调研日期：2026-09-29。采用作者论文、ACL Anthology、PMLR 和 arXiv 原始页面。以下是围绕当前代码的定向调研，不是穷尽检索，也不是学术新颖性保证。未读取正文的文献不用于复述具体网络细节或比较分数。

本项目目前“投影→质量门控→模态注意力→GRU”均由常见组件构成。可能值得研究的是特定实际约束下的机制与证据：质量代理不可靠、传感器连续掉线时，融合是否退化、何时应保留不确定状态。**当前启发式 confidence 不等于校准概率，age=0 不能支持时延鲁棒性的实验结论。**

本轮补充 [Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html) 所讨论的概率校准视角：准确率和置信度可靠性是不同问题。新增 NLL、Brier、ECE 与风险—覆盖曲线只用于诊断，不意味着实现了温度缩放或其他校准算法。

发现 ICASSP 2026 的 [Context-Aware Dynamic Graph Learning](https://ieeexplore.ieee.org/document/11464400/) 相关题录；正文访问被站点验证阻挡，本轮不将其作为已复现方法，也不引用搜索摘要中的性能数字。后续应补全文核对。

## 二 多轮追问

| 文献 | 本轮核对深度 | 对论文定位的约束 |
| --- | --- | --- |
| [FQ-Bank，EACL Findings 2023](https://aclanthology.org/2023.findings-eacl.149/) | PDF 候选构造与排序模型段落 | 已有多轮追问候选排序及 BERT/RoBERTa 监督模型。仅胜过 BM25 不足以支持较强创新主张；需同候选 Cross-Encoder 对比 |
| [FollowupQG，IJCNLP-AACL 2023](https://aclanthology.org/2023.ijcnlp-main.17/) | 官方题录与数据入口；相关论文实验段核对 | 信息寻求追问生成与本项目固定候选排序不同。可作后续外部场景验证来源，当前未纳入主数据 |
| [From Superficial to Deep，COLING 2025](https://aclanthology.org/2025.coling-main.55/) | PDF 方法与实验设置 | 已通过话题识别、外部知识图谱和 LLM 融合生成追问。不能声称首次知识增强或首次探究新信息；本项目应研究轻量选择、已谈覆盖和不可靠知识 |
| [KdConv，ACL 2020](https://aclanthology.org/2020.acl-main.635/) | 沿用官方 README 与本地原始数据，重审改造代码 | 原任务知识对话，不是候选追问相关性数据；改造必须独立命名，采样负例不是人工错例 |
| [KG-Followup，2026](https://arxiv.org/abs/2603.01252) | 作者摘要；页面注明 EACL Findings 2026 | 领域知识图谱辅助医疗追问已有研究；这里只作方法边界参考，不迁移医学结论或引入医疗任务 |

FQ-Bank 正式论文涉及监督语义排序；当前冻结句向量轻量网络只是研究起点。知识双路 attention、gate、位置编码是已有技术。可检验的区分点应是：**在严格历史输入和一致候选协议下，显式区分已经谈过的内容与可用于推进对话的知识，并在知识无关时控制退化。** 是否有贡献，取决于强基线、人工非重复性评估及消融证据，而不是模块数量。

需要特别区分：

- 词汇新颖 ≠ 信息增益；重复实体可能是在合理澄清，新实体可能完全无关。
- 知识与问题重叠 ≠ 知识真实或可回答；当前不做事实核验。
- 下一个观察问题 ≠ 唯一合理问题；单参考 weak labels 可能错罚合理替代问题。
- 给定正确候选的重排 ≠ 从开放问题池召回；当前离线候选保证含参考问题。

## 三 如何形成硕士论文研究贡献

建议使用“研究问题—技术假设—机制—可反驳实验—限制”的写法，避免把每一个修复都称为创新。候选来源捷径审计是重要研究质量工作；位置编码修复是正确建模的基础；公开数据改造是实验协议，不能自动成为新算法贡献。

前两点建议各形成一个清晰的方法章节；第三点形成系统设计与应用验证章节。是否满足具体培养方案中的创新数量和成果要求，应由导师与学院要求确定，不能据当前代码保证毕业条件。

统计方面参考 [Dror et al., ACL 2018](https://aclanthology.org/P18-1128/)。本轮提供按完整对话抽样的配对 bootstrap 区间，避免把同对话的多轮样本当作相互独立。区间针对给定训练后模型的评测数据波动；多个训练种子的波动必须另行报告，不能将三个种子的重复预测拼成三倍独立样本。
