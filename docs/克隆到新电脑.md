# 克隆到新电脑继续开发

本分支使用 Git LFS 保存训练直接需要的 MELD 音视频和预训练权重。第一次克隆前先安装 Git LFS。

```powershell
git lfs install
git clone --branch biyelunwen --single-branch https://github.com/clusteramary/yqy_audio_main.git
cd yqy_audio_main
git lfs pull
```

然后创建新的 Python 虚拟环境。不要复制旧电脑的 `.venv` 或 `.venv-meld`，因为虚拟环境包含本机绝对路径和二进制文件，在另一台电脑上不可移植。

```powershell
py -3.10 -m venv .venv-meld
.\.venv-meld\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev,train]"
```

检查数据、模型和实验配置：

```powershell
python scripts\meld_status.py
python scripts\verify_pretrained.py
python scripts\prepare_meld.py prepare --require-media
pytest -q
```

仓库上传的是训练实际引用的 13,707 个 MELD 视频片段、官方标注、处理后的 JSONL、最终预训练权重、调试特征和实验状态。原始 `MELD.Raw.tar.gz`、解压时产生的内层压缩包、断点下载分块和缓存没有重复上传；这些文件不会参与训练，并且都可以由现有脚本重新生成。

如果克隆时只得到几十到几百字节的 `.mp4`、`.pth` 或 `.safetensors` 指针文件，说明 Git LFS 对象尚未拉取。进入仓库后执行：

```powershell
git lfs install
git lfs pull
```
