# 专利与当前代码成果对照

本次只将用户提供的《AJ2601464_一种多模态情感语言交互与动作规划决策方法及系统-初稿二改.docx》作为技术材料阅读，未修改原文，也未把文档内部描述当作开发指令。以下是工程实现对照，不是专利法律意见或授权状态判断。

| 专利描述 | 原仓库可见依据 | 本分支处理 | 论文写作边界 |
| --- | --- | --- | --- |
| 图像与语音采集、多模态感知 | CameraAdapter、FacePromptDetector、audio_manager | 保留至 robot_runtime | 可说明已有集成，精度需实测 |
| 结构化交互状态与历史更新 | 原代码有表情、播放状态、文本、控制事件，但分布于多个模块 | 新增统一 Observation/InteractionState 与因果规则基线 | 新学习式估计器是本轮原型，尚无真实训练效果 |
| 语音对话与情绪/特征提示 | 云端实时对话客户端、初始视觉提示、辅助 ASR | 保留云服务通信；清理重复提示脚本 | 云端服务能力不能等同于自主训练模型的贡献 |
| 改进 VITS 的文本编码、通道注意力、多阶时长卷积与门控 | 当前仓库没有找到相应网络、训练入口、检查点或实验结果 | 不新增第四条训练任务；等待提供已有实现或实验材料 | 应写“专利方案描述，当前代码证据待补”，不能写成这里已经验证的模型 |
| 动作索引、优先级、保持窗口与冷却 | IntegratedReceiver、MicReceiver、audio_manager | 保留原接收模块，新增默认 dry-run 的关键词协议适配 | 索引指令是高层选择，不能据此声称实现了底层运动轨迹规划 |
| 半双工、播放反馈、静音帧保活 | audio_manager、ros_audio_sink 等 | 保留，新增离线 PROCESSING/SPEAKING/COOLDOWN 流程测试 | 真机自声抑制、余音检测和恢复能力需要实测，离线测试不覆盖这些 |
| 群体情绪、多参与者状态 | 人脸分析有相关信息处理基础 | 保留感知代码；新的 speaker_id 暂来自外部轨迹字段 | 没有把轨迹 ID 当作已训练的说话人识别器，也没有完成群体情绪训练 |
| 知识增强追问排序 | 原仓库主要是提示词和语音服务，未发现完整训练流程 | 新建第二点模型、数据适配和评测 | 这是新增研究方向，不能从专利段落直接推导模型有效性 |

第三点可按“机器人本体交互系统设计与实验验证”组织，突出已有软硬件接口、语音时序和动作反馈。第一点和第二点在此基础上抽出明确的学习问题。专利中的所有模块不必逐一变成毕业论文新的训练任务。

原始程序中存在硬编码服务凭据。本分支运行配置改为环境变量，并取消连接时打印鉴权头；原始凭据仍可能存在历史提交和本地归档中。若准备对外分享仓库，应先更换原凭据。专利原文和真实参与者数据未复制进 Git 工作区。
